# Происхождение материалов и сторонние компоненты

Ядро и API реализованы во время соревнования с помощью Codex. Ниже сохранено происхождение оригинальных материалов; установленные версии перечислены отдельно.

| Компонент | Источник и использование | Условия / статус |
|---|---|---|
| data/*.parquet и data/README.md | Официальные материалы кейса Freedom «Граф денег»; ссылки в docs/hackalem/10_SOURCE_AUDIT.md | По ТЗ — исключительно для хакатона; не переиздавать под лицензией проекта |
| starter/* | Оригинальный starter организатора, сохранён без изменений | Источник раскрыт; отдельная открытая лицензия в пакете не обнаружена, разрешение на использование следует из выдачи для кейса |
| Снимки ТЗ и положения | Официальные пользовательские ссылки и страница хакатона | Справочные копии с атрибуцией, не собственные материалы команды |
| Codex | Помощь в исследовании, проектировании, реализации backend/алгоритмов, тестах и документации зоны A | Разрешённые AI-инструменты по п. 5.4.12 |
| Claude Code | Пользователь заявил доступ у обоих участников; предполагается использование при реализации | Пока не утверждаем фактический вклад в ещё не написанный код |

Предлагаемый стек в документации не равен списку уже установленных зависимостей продукта. При реализации добавить фактические версии и лицензии из metadata пакетов и их LICENSE; сохранить необходимые notices. Не назначать лицензию MIT/Apache чужим исходным материалам по умолчанию. Если появится LLM в приложении, отдельно указать поставщика, модель, какие данные передаются и локальный способ проверки без платной подписки участника.
