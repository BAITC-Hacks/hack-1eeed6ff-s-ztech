# Neverlose — интерфейс (зона B)

Этот каталог содержит UI. Наличие сборки не подтверждает готовность аналитического backend.
Контракт: `../contracts/README.md` и `../contracts/v1.example.json`, опубликованные Мейрамом.
Синтетический fixture используется только тестами; production делает реальные запросы и показывает ошибки.

## Установка и проверка

Из `web/`, Node >=22.12 (фактически проверен Node 25.2.1, npm 11.6.2, macOS 27.0 arm64):

```bash
npm ci
npm test -- --run
npm run build
npx playwright install chromium
npm run test:e2e
```

Браузерные тесты запускают production-сборку на порту 4173 и подменяют только HTTP-транспорт
опубликованным synthetic fixture. Это проверка UI-контракта, не проверка настоящего расчёта.
Зависимости и браузер устанавливаются из сети; UI не загружает внешние шрифты, скрипты или аналитику.

```bash
npm run dev
```

Vite проксирует `/api` и `/health` на `http://127.0.0.1:8000`.
Без запущенного backend будет честная ошибка. Скрытого `.env` или API-ключа нет.
Для backend-раздачи использовать `web/dist` и регистрировать API перед SPA catch-all.

В этой рабочей сессии Chromium установлен в отдельный каталог задачи: перед E2E задан
`PLAYWRIGHT_BROWSERS_PATH=/Users/mrxfsociety/Documents/Codex/2026-09-23/new-chat/work/pw-browsers`.
Это путь тестового окружения, не требование приложения и не переносимая зависимость.

Результаты этапов: `../docs/progress/B.md`. Непроверенные функции не считаются готовыми.
