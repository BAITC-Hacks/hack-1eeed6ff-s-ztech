# Neverlose — интерфейс (зона B)

Этот каталог содержит интерфейс, проверенный с настоящим локальным API на backend
`3e8c09a8f169a407b5206f45fd9586055babb15a`. Это версия зоны B, которую Мейрам интегрирует в main.
Контракт: `../contracts/README.md`, synthetic `../contracts/v1.example.json`
и настоящий пример `../contracts/v1.actual.json`, опубликованные Мейрамом.
Синтетический fixture используется только тестами; production делает реальные запросы и показывает ошибки.

## Установка и проверка

Из `web/`, Node >=22.12 (фактически проверен Node 25.2.1, npm 11.6.2, macOS 27.0 arm64):

```bash
npm ci
npm test -- --run
npm run build
npx playwright install chromium
npm run test:e2e
```

Браузерные тесты запускают production-сборку на порту 4173 и подменяют только HTTP-транспорт
опубликованным synthetic fixture. Это проверка UI-контракта, не проверка настоящего расчёта.
Зависимости и браузер устанавливаются из сети; UI не загружает внешние шрифты, скрипты или аналитику.

```bash
npm run dev
```

Vite проксирует `/api` и `/health` на `http://127.0.0.1:8000`.
Без запущенного backend будет честная ошибка. Скрытого `.env` или API-ключа нет.
Для backend-раздачи использовать `web/dist` и регистрировать API перед SPA catch-all.

## Настоящее приложение

Готовая сборка `web/dist` включена в Git. Из корня репозитория с установленными Python
зависимостями выполните `python run.py`, затем откройте `http://127.0.0.1:8000`.
Для обычного просмотра Node/npm не нужны. Для независимой проверки настоящего API
сначала запустите этот сервер, затем из `web/`:

```bash
npm run test:integration
```

Этот набор не подменяет HTTP-ответы: три desktop-размера, карточка, boundary, изолят,
произвольные gid, суммы переводов, кластер и реальные скачивания. CSV сверяются побайтно
с API и `../results`. Если сервер запущен на другом порту или с `--out`, задайте
`NEVERLOSE_BASE_URL=http://127.0.0.1:8001` и `NEVERLOSE_RESULTS=/полный/путь/к/результатам`.
Это параметры тестов, не скрытая конфигурация приложения.

Порядок работы: выберите строку очереди или введите полный gid → проверьте направленный
граф и карточку → нажмите сумму входа/выхода для исходных переводов → откройте альтернативу
и ограничения в карточке → выберите CSV в шапке и скачайте. «Таблица связей» даёт
доступную альтернативу canvas. На 1024×768 используйте вкладки «Сеть / Приоритеты /
Карточка» и «Граф / Переводы». Enter выполняет поиск, Escape возвращает фокус в поиск.

Ошибки API показываются явно с повтором. Поиск сбрасывает фильтры и не округляет gid.
При смене run_id панели очищаются до обновления. Чата и симуляции агента нет.
Подробности: [архитектура](../docs/architecture.md), [демо](../docs/demo.md).

## Проверка без внешней сети на macOS

После установки зависимостей и Chromium из корня репозитория:

```bash
sandbox-exec -f web/scripts/offline-macos.sb .venv/bin/python run.py --port 8001
```

В другом терминале, из `web/`:

```bash
NEVERLOSE_BASE_URL=http://127.0.0.1:8001 sandbox-exec -f scripts/offline-macos.sb npm run test:integration
```

Профиль разрешает только loopback для сервера и дочерних процессов браузера.
Внешний TCP-запрос фактически получил EPERM, Chromium — ERR_ACCESS_DENIED;
локальный `/health` вернул 200, все 3 integration-сценария прошли.
Системный Wi-Fi при этой проверке не выключался. `sandbox-exec` доступен на проверенной
macOS 27.0, это отдельный тестовый инструмент, не runtime-зависимость и не инструкция для Windows/Linux.
Доказательства и ограничения: `evidence/r1/`, [журнал B](../docs/progress/B.md).

В этой рабочей сессии Chromium установлен в отдельный каталог задачи: перед E2E задан
`PLAYWRIGHT_BROWSERS_PATH=/Users/mrxfsociety/Documents/Codex/2026-09-23/new-chat/work/pw-browsers`.
Это путь тестового окружения, не требование приложения и не переносимая зависимость.

Результаты этапов: `../docs/progress/B.md`. Непроверенные функции не считаются готовыми.
