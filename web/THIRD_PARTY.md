# Frontend dependencies

Версии зафиксированы в package-lock.json. Компоненты интерфейса написаны в этой сессии с Codex.
Готовые шаблоны приложения, внешние шрифты и сторонние аналитические сервисы не используются.
В B6 добавлен логотип Freedom из предоставленного пользователем файла Freedom.svg.

| Компонент | Версия | Лицензия / источник |
|---|---|---|
| React / React DOM | 19.1.1 | MIT, https://github.com/facebook/react |
| Cytoscape.js | 3.33.1 | MIT, https://github.com/cytoscape/cytoscape.js |
| Vite | 7.3.6 | MIT, https://github.com/vitejs/vite |
| Vitest | 4.1.11 | MIT, https://github.com/vitest-dev/vitest |
| TypeScript | 5.9.2 | Apache-2.0, https://github.com/microsoft/TypeScript |
| Playwright | 1.55.1 | Apache-2.0, https://github.com/microsoft/playwright |

Вспомогательные типы и plugin-react: точные версии/зависимости в lock-файле;
лицензии установленных пакетов сохраняются в их LICENSE. Chromium используется только для тестов.
Оригинальные материалы хакатона и fixture принадлежат общему проекту и не представлены как UI-разработка.


## Предоставленный логотип Freedom

`src/assets/freedom.svg` — исходный файл пользователя, полученный 23.09.2026.
`src/components/FreedomLogo.tsx` — те же векторные пути в JSX; цвет надписи
адаптируется к теме, компактный вариант ограничивает область видимости знаком.
SVG не скачивался из стороннего пакета и не создан командой. Название и знак
принадлежат их правообладателю; отдельная открытая лицензия пользователем не
предоставлена. Они не перелицензируются как собственный код Neverlose.
Использование в хакатонном интерфейсе выполнено по прямому запросу пользователя;
заявление о банковской аффилиации или официальном продукте отсутствует.
