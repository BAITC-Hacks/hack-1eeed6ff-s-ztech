# Независимый аудит Neverlose MVP

23 сентября 2026, macOS 27.0 (26A428), Apple M2. Оценка техническая, с позиции банковского аналитика; это не официальное заключение Freedom Bank.

## Честная оценка: 9/10 как локальный MVP

Первичная оценка была 8/10. После второго цикла исправлены дополнительные воспроизводимые ошибки фокуса, доступности и проверки оснований. Повышение оценки относится к качеству проверенного MVP, а не к готовности промышленной банковской системы. Обязательные backend-функции по официальному кейсу присутствуют.

До честных 10/10 не хватает проверки полезности с реальными аналитиками, независимой разметки качества гипотез и более широкой эксплуатационной приёмки. Нельзя компенсировать это красивым интерфейсом или числом автоматических тестов. Роли и приоритеты остаются объяснимыми гипотезами, не вероятностью виновности.

## Что хорошо

- Основной сценарий работает локально без API-ключа и подписки, после установки — с запрещённой внешней сетью.
- Один воспроизводимый расчёт связывает UI, API и три CSV через run_id; суммы в тиынах, длинные gid сохраняются точно.
- Есть направленный граф, поиск по всему набору, карточка с правилом и альтернативой, реальные переводы и ссылки на исходные строки.
- Boundary и изолированные seed не скрыты и не интерпретируются как доказательство накопления.
- Две спокойные темы, плавный вход с reduced motion, понятный возврат, таблица и разворот сложного графа.
- Ошибки API показываются честно; production-подмены fixture нет. Агентская панель показывает реальные серверные источники/инструменты; без включённого backend это явно недоступная функция.
- README, lock-файлы, проверки результата, история и фактический журнал позволяют воспроизвести работу.

## Оставшиеся ограничения

- Нет размеченной оценки accuracy/precision/recall и исследования удобства с банковскими аналитиками; полезность приоритизации пока не доказана такой проверкой.
- Плотный граф на небольшом экране требует zoom, разворота или таблицы. Он не превращён в декоративную иллюстрацию с выдуманными связями.
- Для промышленной работы потребуются управление доступом, дела/сохранённые расследования, аудит действий, политика хранения и эксплуатационные процедуры. Локальный MVP не предлагается разворачивать публично как банковскую систему.
- E1 доступен в backend без UI; E2 отсутствует. Million-scale, длительная нагрузка, Windows/Linux и полноценная работа со screen reader не проходили приёмку.
- Платный AI в этом аудите не вызывался. Положительные UI-сценарии проверены синтетическим контрактом; настоящий сервер честно работает с features.agent=false. Исторические live-проверки Мейрама не выданы за наш новый прогон.
- Нулевые известные advisories не означают отсутствие неизвестных уязвимостей. Это ограниченный аудит, не полный пентест и не банковская сертификация.

Открытых подтверждённых P0/P1 в проверенной области не найдено. Формулировка «найдены все баги» не используется.
