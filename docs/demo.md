# Демо Neverlose — до пяти минут

Показываем локальный расчёт и реальный API, без внешней модели, подписки и ключа.
Целевой сценарий 4:30, оставшиеся 30 секунд — запас. Статус репетиции указан ниже;
тайминг речи в таблице является планом, не измерением выступления человека.

## Подготовка

1. Получить интегрированную ветку с `web/dist`, установить зависимости по README.
2. Запустить `python run.py`; открыть `http://127.0.0.1:8000` в браузере.
3. Оставить терминал в корне с активным `.venv`; для живого пересчёта использовать
   отдельный output: `python run.py --pipeline-only --out work/demo-results`.
   Убедиться, что run_id совпадает с обслуживаемым набором. Это не обновляет живой
   snapshot сервера: новый набор потребовал бы его перезапуска.
4. Размер окна 1440×900 либо 1280×800. На 1024×768 есть вкладки рабочих панелей.
5. На стартовом экране выбрать светлую/тёмную тему и нажать «Открыть платформу».
   Повторно открыть заставку можно нажатием Neverlose; анимацию ждать не требуется.
   Для возврата из узла/кластера нажать стрелку «На главный экран» слева в шапке. Ничего не устанавливать во время выступления.
   После установки сценарий проверен при запрете внешней сети; подробнее в журнале B.

## Примеры для проверки, не ответы алгоритма

Для run_id `c4894b7dbe3a21e042250ec621491f817f1fb61db1ece87c1771ee668786795d`:

- Первый по приоритету `100000008346837100`: консолидация, альтернатива — распределение.
- Boundary `100000001053894100`: ограничение depth=4, не вывод о накоплении.
- Изолированный seed `100000000456947100`: 1 узел / 0 связей, непустая карточка.

Эти gid взяты из готового результата, в код приложения не зашиты. Для случайного raw-gid
в активном Python-окружении можно выполнить:

```bash
python -c 'import secrets, pyarrow.parquet as pq; print(secrets.choice(pq.read_table("data/nodes.parquet", columns=["gid"]).column("gid").to_pylist()))'
```

## Если что-то не сработало

При HTTP/сетевой ошибке показать настоящий текст, восстановить сервер и повторить запрос.
При смене run_id нажать «Обновить»; не смешивать старые карточки и новые выгрузки.
Если заданного gid нет, показать честный ответ и выбрать другой gid из raw.
Если времени мало, оставить поиск → граф → основание → boundary → CSV, опустить
дополнительный разбор кластера и изолята. Не убирать ограничения выводов.
