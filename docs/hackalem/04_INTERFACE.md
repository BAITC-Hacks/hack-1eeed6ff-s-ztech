# Интерфейс: рабочее место аналитика

## 1. Визуальная идея

Строгий аналитический инструмент: тёмный графитовый фон, тонкие границы, светлая типографика, ограниченный набор функциональных цветов. Главные акценты — выбранный узел и объяснение решения. На первом экране сразу настоящие данные; отдельная маркетинговая landing page не нужна.

**Прямое требование пользователя: профессионально, без AI-slop, без шаблонного AI-дизайна, без градиентов.** Запрещены CSS/SVG/canvas-градиенты, glow, glassmorphism, декоративные mesh-фоны, aurora, огромный hero, AI-sparkles и универсальная сетка маркетинговых карточек. Нельзя маскировать эти элементы другим названием. Плоские заливки и функциональная визуализация графа разрешены. Финальный UI проверяется визуально и поиском запрещённых эффектов в исходниках; одной проверки текста CSS недостаточно.

Избегать декоративного неона, огромных заголовков, бесконечных «живых» точек, фальшивых загрузок «AI думает», случайных процентов, чрезмерной стеклянности. Важное число всегда имеет единицу, период и понятное происхождение.

Точные размеры: верхняя панель 56px, полоса показателей 64px, внешние отступы 16px, зазоры 12px. Левая колонка 264px, правая 360px, центр `minmax(360px,1fr)`. Основные панели со своим scroll, без горизонтального scroll всей страницы. На 1280px левая 232px, правая 328px. Ниже 1180px карточка — выдвижная панель, закрываемая Escape; очередь остаётся доступной. На 1024px включать вкладки «Сеть / Приоритеты / Карточка» вместо трёх сжатых колонок.

## 4. Граф

- Начальное состояние — обзор кластеров с направленными агрегированными связями; рядом очередь приоритетов. Не пытаться сразу разместить 2 248 подписей.
- Клик по кластеру раскрывает подграф; клик по приоритетному узлу — ego-граф. Кнопка «Вся сеть» допускает общий обзор с скрытыми подписями, но не нужна для прохождения основного сценария.
- Направление всегда arrowhead; ширина ребра по log1p суммы с пределами 1…5px, число рядом только у выбранного ребра. Ребро означает наблюдаемые переводы, не командную связь.
- Размер узла 14…34px по priority, без гигантских кругов, закрывающих соседей.
- Seed — отдельное кольцо и текстовый badge; boundary — пунктирное кольцо и badge «Граница выборки»; выбранный узел — дополнительная светлая обводка.
- Default layout ego — concentric вокруг root, порядок по расстоянию и стабильному gid. Для кластеров допустим ограниченный cose; не запускать повторно при каждом hover.
- До 250 узлов в интерактивном подграфе по контракту, с честной подписью лимита. Все узлы остаются доступны поиском и через таблицу, лимит не удаляет их из расчёта.
- Кнопки: приблизить, отдалить, fit, сброс выбора, переключить 1/2 шага. По умолчанию 1 шаг.
- Выбранный узел сохраняется при открытии/закрытии подробностей. Новый поиск отменяет предыдущий запрос; запоздалый ответ не заменяет актуальную карточку.
- При unmount вызывать destroy экземпляра Cytoscape и очищать listeners; не создавать новый canvas на каждое изменение текста.

По [рекомендациям Cytoscape.js](https://js.cytoscape.org/#performance) ограничивать постоянно видимые подписи и анимации, пакетировать обновления. Это помогает сохранить отзывчивость на графах с большим числом элементов; фактическое время требуется измерить.

## 5. Карточка узла

Верх: полный gid, кнопка копирования, cluster_id, depth, seed/boundary/isolate. Никаких вымышленных имени, фотографии, организации или географии.

Следом — роль, role_score с подписью «Соответствие правилу», priority с подписью «Приоритет проверки». Tooltip объясняет различие. Не рисовать score как «вероятность вины».

Вкладки карточки:

1. **Обоснование:** summary, 3–5 числовых фактов, условия правила и ограничения score.
2. **Гипотезы:** сравнение основной и альтернативной роли по одним признакам; выполненные и невыполненные условия. Если альтернативы нет — честное сообщение, а не вымышленный конкурент.
3. **Данные:** вход/выход KZT, контрагенты, операции, исходные строки. Детальная таблица также доступна внизу центральной области.

Блок «Что проверить дальше» всегда видим ближе к концу карточки. Клик по сумме устанавливает направление фильтра таблицы переводов. Сумма всей выборки direction берётся с backend, не складывается только по текущей странице из 50 строк.

## 6. Очередь и кластеры

Очередь содержит rank, сокращённый gid, role label, priority, краткую причину и флаг наблюдения. Сокращение только визуальное: tooltip/copy дают полный gid. Default top-50, минимум 20 по ТЗ. Номер строки не притворяется официальным решением о проверке.

Фильтры role/cluster/boundary/seed с chips и кнопкой «Сбросить». Фильтрация не перенумеровывает глобальный ранг как новый риск и не меняет score. Если нужен ранг в текущем представлении, явно подписать его отдельно. Поиск gid работает по полному набору, даже если текущий фильтр скрывает узел.

Карточка кластера: n_nodes, n_seed, внутренний оборот, число boundary, распределение ролей, три главных gid, межкластерные вход/выход и осторожная гипотеза. Доли ролей делятся на число узлов этого кластера, не на всю сеть.

## 7. Состояния, которые нельзя пропустить

| Состояние | Что видит пользователь |
|---|---|
| Вычисления ещё не готовы | Этап расчёта и фактический статус; без случайного процента |
| Не выбран узел | Краткая инструкция «Выберите узел в очереди или найдите gid» |
| Изолированный seed | Один узел, ноль связей, понятное ограничение, непустая карточка |
| Узел boundary | Видимое предупреждение о четвёртом колене, запрет вывода о накоплении |
| Пустой фильтр | «Ничего не найдено», сброс фильтров |
| Несуществующий gid | «Такого gid нет в этой выгрузке», ввод сохраняется |
| Невалидный ввод | Текстовая ошибка у поиска, запрет преобразования в number |
| API недоступен | Понятная ошибка и повтор; не показывать synthetic fixture вместо данных |
| Ответ устарел | Старый запрос отменён/проигнорирован по request id |
| Граф ограничен | «Показано X из Y», объяснение правила отбора |
| CSV скачан | Реальный файл, совпадающий с активным run_id |
| Метрика не определена | «Недостаточно наблюдений», не 0% |

## 8. Доступность и полировка

Клавиатура: Tab до поиска, списка, кнопок; Enter запускает поиск; Escape закрывает drawer. Рядом с icon-only кнопкой accessible label. Видимый focus, кликабельная цель минимум 32px. Граф дублируется таблицей соседей/переводов: основные факты доступны без точного клика по маленькой точке.

Уважать reduced-motion. Переходы 120–160ms, без автоматической вращающейся камеры. Скриншоты для проверки: overview, selected node, boundary, isolate, unknown gid, narrow desktop, error. Проверка настоящим браузером обязательна; успешный build не подтверждает качество интерфейса.

## 9. Что показывать за пять минут

Обзор → приоритетный узел → факты и переводы → альтернативная гипотеза → граничный узел → случайный gid от жюри → CSV и живой запуск. E1 показывать только если остаётся время в демо и реализация прошла проверку. На сцене не открывать секреты, личные аккаунты и бесконечные логи; вывод команды должен кратко показать число строк, время и успешную проверку.
