## Как работает агент

Пользователь отправляет вопрос и по желанию выбранный gid. OpenAI выбирает read-only инструменты backend, получает факты текущего расчёта и выбирает основания ответа. Сервер допускает только ID фактов, реально полученных инструментами; числа, ссылки и source_ref берутся из расчёта. Панель показывает фактический журнал и сохраняет ответ в Markdown.

Два новых вопроса выполнены из настоящего браузера: один разобрал основную и альтернативную роли, другой вернул исходные переводы. Всего 5 обращений к модели,12168 входных/539 выходных токенов. Это отдельные live-проверки, не mock. При B6 и clean clone платные запросы не повторялись. [Ответ с переводами](evidence/agent-ui-a/final-answer.md).

Границы: есть поиск общих прямых получателей2–5явноуказанныхсчетов. Нет поиска путей, временных фильтров и произвольных вычислений. Обзор содержит 5 лидеров, соседи ограничены 20 связями. Источники подтверждают факты, но не гарантируют полноту ответа на любой вопрос. При выключенном режиме, ошибке или недостаточных данных UI показывает соответствующее состояние. На старте ключ не нужен; для агентского режима жюри заполняет свой локальный `.env` по README.

## Что действительно стоит добавить следующим

1. **Маршруты после общего получателя.** Общие прямые получатели уже реализованы по явному поручению пользователя; многозвенные пути остаются отдельной задачей с ограничениями происхождения/повторного оборота денег.
2. **Сохраняемое досье исследования.** Вопросы, основания, гипотезы и следующий запрос данных в одном деле с run_id. Это помогает передать работу коллеге; для банка далее нужны права доступа и журнал изменений.
3. **Сравнение временных срезов.** Проверить устойчивость найденной структуры между периодами; текущая выгрузка и точность до дня ограничивают выводы.

Следующие идеи не внедрялись; общие прямые получатели добавлены отдельным явно одобренным этапом. Текущий визуал имеет последовательную палитру, ясные панели и обе темы; сохранён дизайн Алишера. Следующее точечное UX-улучшение — компактная сводка ответа агента с раскрываемыми основаниями: сейчас длинный ответ требует заметной прокрутки.
