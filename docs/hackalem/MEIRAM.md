## 4. Самые опасные ошибки в твоей зоне

- gid выше 2^53−1: никаких float-преобразований, `iterrows` с upcast или JSON number.
- 97 повторяющихся tx не удалять; source_row присваивать до сортировки.
- G должен содержать все 2 248 nodes, даже без рёбер; 19 изолированных seed отдельными кластерами.
- 444 boundary не объявлять terminal. 354 out>in с положительным входом и 23 с нулевым — разные категории.
- Суммы — тиыны, агрегаты tx сверяются с edges. Никаких неявных округлений больших ID.
- Сначала кластеризация, затем participation и роли. Проекция Louvain складывает встречные веса.
- Betweenness не использует сумму как длину пути. Приближение k=128/seed=42 документировать.
- В evidence только рассчитанные цифры; ≤200 символов в CSV. Альтернатива не должна быть выдуманной вероятностью.
- Top ранжируется по полному score, ties по gid; экспорт/API/UI используют один snapshot/run_id.
- Не требовать API-ключей, GPU, банка/облака или личной подписки для проверки жюри.

Точные формулы уже определены в 02_DATA_ALGORITHMS.md. Не изобретать вторую несогласованную модель; менять общие правила можно после выявленного дефекта и повторной проверки, не ради нужного gid.

## 5. Как фиксировать и проверять работу

После каждого A-этапа запускать его тесты, проверить diff отдельным проходом, исправить P0/P1, записать `docs/progress/A.md`, обновить STATUS, сделать содержательный commit и push. Алишеру передавать **SHA + готовые endpoint/поля + известные ограничения**, а не «backend готов».

Перед каждым концом часа собрать реальный результат команды в docs/progress/hour-N.md. Час 1 уже имеет аудит/импорт; не подделывать код, которого в нём не было. Техническое решение о достаточности почасового результата принимает организатор.

Целевые команды после реализации:

```bash
python -m pytest tests -q
python run.py --pipeline-only --data data --out results
python run.py --verify-only --data data --out results
python run.py
```

Они пока являются контрактом разработки. После реализации проверь их и только затем представь в README как готовые.
