## Запуск экспертом

Нужен установленный Python 3.12. Доступ к приватному репозиторию предоставляет организатор; runtime личного аккаунта участника не требует.

```bash
git clone https://github.com/BAITC-Hacks/hack-1eeed6ff-s-ztech.git
cd hack-1eeed6ff-s-ztech
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
python run.py
```

При настроенном SSH можно использовать `git clone git@github.com:BAITC-Hacks/hack-1eeed6ff-s-ztech.git`. Открыть `http://127.0.0.1:8000`; при занятом порте — `python run.py --port 8001`. Остановка — Ctrl+C. Node/npm не нужны для просмотра включённого `web/dist`.

## Границы версии

Роли — структурные гипотезы; score не является вероятностью виновности. Неполные входы, depth=4, порог 5000 KZT, июль и один банк видны в UI. 97 одинаковых строк сохранены; accuracy без ground truth не заявляется.

E1 — проверенный API структурной симуляции удаления 1–3 узлов; панель E1 в интерфейсе пока отсутствует и не демонстрируется как готовая функция. E2 не вошёл. AI-аналитик доступен через панель/API/CLI при явном включении и наличии своего OpenAI-ключа, основной сценарий от него не зависит. Модель выбирает инструменты и проверенные утверждения; детерминированное ядро отдельно. Windows/Linux, Safari/Firefox и million-scale не проходили приёмку.

Техническая репетиция B заняла 141.218 s и подтверждает маршрут действий/выгрузки; устную речь человека она не измеряет. Команде нужно произнести сценарий с собственным таймером.
